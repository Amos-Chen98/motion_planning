# data_review

> **Note:** This README was generated by AI and may contain inaccuracies. Please verify against the source code.


Data analysis and visualization scripts for anchor navigation planning experiments.


## Utility Modules (not run directly)

| File | Description |
|------|-------------|
| `ieee_figure_config.py` | Configures matplotlib with IEEE-journal style (Times New Roman, font sizes, colors). Imported by all plotting scripts. |
| `planning_logger.py` | `PlanningLogger` class used by the planner ROS node to write `planning_session_*.json` log files. |

## Analysis Scripts

| File | Description | Key Input |
|------|-------------|-----------|
| `analyze_data_range_from_csv.py` | Prints min/max of `initial_x` and mean/std of `initial_y`, `initial_yaw` from a planning CSV. | CSV path hardcoded at top |
| `analyze_traj_velocities.py` | Loads a trajectory JSON and reports max linear velocity, yaw rate, and per-joint angular velocities. | `TRAJECTORY_FILENAME` hardcoded at top |
| `analyze_traj_from_rosbag_csv.py` | Reads a rosbag-exported CSV and generates IEEE-style plots of joint angles and position/yaw (actual vs. desired). | `CSV_FILENAME` hardcoded at top |
| `analyze_hyperparam_from_log_folder.py` | Groups JSON planning logs by `(sample_density, transform_attempt_num)` and prints success rates and average computation times. | Log folder hardcoded at top |
| `analyze_ablation_benchmark_from_log_folder.py` | Reads ablation-study JSON logs, writes a CSV summary, and generates scatter plots comparing algorithms. | Log folder hardcoded at top |
| `find_max_time_gaps.py` | Parses timestamps from `planning_session_*.json` filenames and reports the top-N largest time gaps between sessions. | `LOG_FOLDER_PATH` and `TOP_N_GAPS` hardcoded at top |

## Plotting Scripts

| File | Description | Key Input |

## Usage

All scripts are run directly with Python. Input paths are hardcoded at the top of each file — edit them before running:

```bash
python3 <script_name>.py
```

Set `SAVE_PLOTS = True` (where available) to export figures as PDF/PNG instead of displaying interactively.
