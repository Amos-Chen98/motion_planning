## Overview
Batch testing system for running multiple test scenarios with progress tracking and resume capabilities.

## Files Structure

```
bash/
├── run_batch_tests_ablation.sh    # Batch testing for ablation study
├── run_batch_tests_hyperparams.sh # Batch testing across hyperparameter grid

├── run_simulation_hyperparams.sh  # Single simulation runner with hyperparams

├── run_full_pipeline.sh           # Run full multi-package pipeline sequentially

├── verify_log_integrity.sh         # Log file verification tool
└── bash_logs/
    ├── progress/                   # Progress tracking files
    │   └── batch_test_*_progress.txt
    └── batch_test_*_summary.txt    # Test execution logs
```

## Script Descriptions

| Script | Description |
|--------|-------------|
| `run_batch_tests_ablation.sh` | Runs all predefined scenarios across ablation-study configurations (defined in `test_config.sh`). Supports resume. |
| `run_batch_tests_hyperparams.sh` | Runs all predefined scenarios across a `sample_density` × `transform_attempt_num` hyperparameter grid. Supports resume. |
| `run_simulation.sh` | Runs a single simulation. Accepts world, spawn pose, target pose, and planner flags as arguments, or uses defaults. |
| `run_simulation_hyperparams.sh` | Like `run_simulation.sh` but also accepts `sample_density` and `transform_attempt_num` as extra arguments. |
| `run_dynamic_env.sh` | Tests planner behavior when the point cloud switches mid-execution between two hardcoded world environments. |
| `run_full_pipeline.sh` | Sources all ROS workspaces and sequentially runs batch simulations from `squeeze_navigation` then `motion_planner`. |
| `generate_test_scenarios.py` | Generates random test scenarios (initial/target pose) within configurable boundaries. Output is copy-pasteable into bash arrays. |
| `test_config.sh` | Defines `PREDEFINED_TEST_SCENARIOS` and `CONFIGS` arrays used by the batch scripts. |
| `verify_log_integrity.sh` | Checks that all expected `planning_session_*.json` log files are present for a batch run. |

## Quick Start

### 1. Configure Tests
Edit `test_config.sh` to customize your test scenarios:

```bash
# Modify test scenarios
declare -a PREDEFINED_TEST_SCENARIOS=(
    "spawn_x spawn_y spawn_yaw target_x target_y target_yaw"
    # Add more scenarios...
)

# Modify configurations
declare -a CONFIGS=(
    "find_anchor is_parallel run_traj_opt"
    # Add more configurations...
)
```

### 2. Run Batch Tests
```bash
cd /path/to/bash
./run_batch_tests_ablation.sh
```

### 3. Resume Interrupted Tests
```bash
./run_batch_tests_ablation.sh
# Select the session number to resume
```

## Session Management

### List All Sessions
```bash
ls bash_logs/progress/*_progress.txt
```

### Check Session Progress
```bash
cat bash_logs/progress/batch_test_YYYYMMDD_HHMMSS_progress.txt
```

### Clean Up Old Sessions
```bash
# Remove completed sessions
rm bash_logs/progress/batch_test_*_progress.txt
rm bash_logs/batch_test_*_summary.txt
```

## Troubleshooting

### Tests Not Resuming
- Check if progress file exists in `bash_logs/progress/`
- Verify file permissions

### Log Files Missing
- Run `verify_log_integrity.sh` to check
- Ensure sufficient disk space

### Multiple Incomplete Sessions
- Choose the most recent session or clean up old sessions
